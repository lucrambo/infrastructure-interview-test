Cause, isolated with `repo.find`: `order: { id: "ASC", categories: { id: "ASC" } }` + `take: 3` gives 2 posts, and `order: { id: "ASC" }` + `take: 3` gives 3. `src/controller/PostGetAllAction.ts:17-22`. The C14 tests create exactly one category per post (`posts.test.ts:30`), so they can't see it | Drop the nested `categories` order from the paged `find`. Not reproduced, because Windows has no POSIX signals | Use `signals.on` and keep the `draining` guard.
